13. usage of tmux
 from https://www.ruanyifeng.com/blog/2019/10/tmux.html
 13.1 create new session
        tmux new -s <session name>
 13.2 seperate session
        tmux detach
 13.3 list all the sessions
        tmux ls or tmux list-session
 13.4 attach the session
        tmux attach -t <session-name>
 13.5 kill session
        tmux kill-session -t <session-name>
 13.6 switch session
        tmux switch -t <session-name>
 13.7 rename session
        tmux rename-session -t <old-name> <new-name>
 13.8 exit session
        ctrl+d or enter exit

20. add env variable in linux
//1,使用export命令
export PATH=$PATH:/opt/software/node-v8.9.3-linux-x64/bin/node

//export使用方法为 export PATH=$PATH:路径1:路径2:路径n;$PATH为系统变量,表示之前所有设置的路径，如果不加则之前所有的路径都失效。所以必须加上。

//2,修改配置文件/etc/profile
vi /etc/profile
在里面加入:export PATH=$PATH:/opt/software/node-v8.9.3-linux-x64/bin/node

//如果是修改用户主目录下的.bash_profile，则添加的环境变量只对该用户有效，修改/etc/profile对所有用户都生效。也可以修改/etc/rc.local文件和/root/.bashrc文件。
//修改好配置文件后执行source /etc/profile 或者 source /root/.bashrc使配置文件生效

22. usage of rar
1. rar
rar a test.rar file1 file2　　#压缩
2. unrar
unrar e test.rar DestPath　　#解压（会在把当前压缩包内容解压到当前目录内，容易造成解压内容和当前目录原文件混合，不容易区分，不建议使用）
unrar x test.rar DestPath　　#解压（会在当前解压目录内产生一个以压缩包名字命名的目录，目录内是解压内容，推荐使用）

check: https://www.cnblogs.com/yangzhaon/p/12861627.html
